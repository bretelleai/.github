## Bretelle

API LLM compatible OpenAI, opérée par Mazlo, société française. Chaque clé fixe sa zone de traitement : Union européenne, Suisse, ou proxy sous contrat vers les éditeurs américains. Une requête peut restreindre la zone de sa clé, jamais l'élargir, et chaque requête laisse une ligne au registre de passage : date, zone, pays de traitement, tokens, coût.

Vous changez l'URL de base, vous gardez votre SDK.

## Bretelle (English)

An OpenAI-compatible LLM API operated by Mazlo, a French company. Each key sets its processing zone: European Union, Switzerland, or a proxy under contract to the US vendors. A request can narrow its key's zone, never widen it, and every request leaves a line in the crossing log: date, zone, country of processing, tokens, cost.

Change the base URL, keep your SDK.
